# 포스트 작성 가이드

`src/content/tech/` 및 `src/content/projects/` 하위 포스트를 작성·수정할 때 적용하는 공통 기준이다.

## 1. 문서 구조 및 문체

- **제목**: 핵심 대상과 기술적 맥락을 명확히 드러내는 명사구 형태로 작성한다.
- **본문 서술**: 개념 정의, 아키텍처 특성, 설계 근거를 중심으로 객관적인 평서문과 개조식 구조로 서술한다.
- **주제 집중**: 요청받은 주제와 게시글의 목적에 집중하여 작성한다. 목적과 동떨어진 내용이나 당연한 일반론은 덧붙이지 않는다.

## 2. 기술 서술 원칙

- **공통 원리 우선**: 특정 제품·벤더·문법에 종속된 예시(특정 DBMS 옵션, 특정 프레임워크 전용 문법 등)는 지양하고, 해당 기술 영역 전반에 공통으로 적용되는 개념과 메커니즘 중심으로 작성한다.
- **접근성**: 이미지 등 비텍스트 요소에는 대체 텍스트(`alt`)를 명시한다.

Astro는 정적 콘텐츠 중심 웹사이트 구축에 특화된 웹 프레임워크로, 불필요한 JavaScript 실행을 최소화하고 검색 엔진 친화적인 정적 HTML을 생성하는 데 목적을 둔다.

## 1. Zero JS 기반 사전 렌더링
- **불필요한 JS 번들 배제**: 빌드 시점에 컴포넌트를 순수 HTML과 CSS로 사전 렌더링하여 클라이언트로 전송되는 불필요한 JavaScript 번들을 배제한다.
- **초기 로딩 최적화**: 런타임 자바스크립트 파싱 및 실행 비용이 발생하지 않아 빠른 초기 로딩 속도를 보장한다.

## 2. 사전 빌드 최적화 및 정적 HTML 배포
- **정적 배포 적합성**: 모든 페이지를 빌드 시점에 정적 HTML 파일로 사전 생성하므로, 동적 런타임 서버 없이도 일반 웹서버나 CDN(GitHub Pages 등)에 최적화된 상태로 배포할 수 있다.
- **서버 안정성 확보**: 정적 자산 서빙 방식으로 서버 부하를 최소화하고 높은 응답 신뢰성을 제공한다.

## 3. 부분 하이드레이션과 React 결합
- **아일랜드 아키텍처(Islands Architecture)**: 화면 전체를 자바스크립트로 감싸지 않고, 사용자 인터랙션이 필요한 특정 영역만 개별 아일랜드 단위로 분리한다.
- **React 컴포넌트 통합**: 기본 Astro 템플릿 위에 React 등 기존 프론트엔드 라이브러리 컴포넌트를 필요한 요소에만 선택적으로 결합하고 부분 하이드레이션(`client:*`)을 적용할 수 있다.

## 4. 검색 엔진 최적화(SEO)
- **크롤링 효율성**: 완성된 정적 HTML 문서 형태로 제공되므로 클라이언트 사이드 렌더링(CSR)에 비해 검색 엔진 크롤러가 본문 내용을 누락 없이 빠르게 색인한다.
- **시맨틱 구조 유지**: 사전 빌드 단계에서 시맨틱 HTML 및 메타 태그가 온전히 포함되어 검색 노출 경쟁력을 확보한다.

# Astro를 선택한 이유

블로그나 지식 저장고 같은 콘텐츠 중심의 사이트에서 성능은 매우 중요합니다.

## 1. Zero JavaScript (기본값)
Astro는 필요한 컴포넌트만 JavaScript를 로드하는 Islands Architecture를 사용합니다.

## 2. 콘텐츠 위주의 개발 경험
마크다운과 MDX를 완벽하게 지원하여 글을 쓰는 데 집중할 수 있게 해줍니다.

## 3. SEO 최적화
서버 사이드 렌더링(SSR)과 정적 사이트 생성(SSG)을 모두 지원하여 검색 엔진 최적화에 유리합니다.

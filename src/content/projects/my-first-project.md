# 프로젝트 개요

이 프로젝트는 나만의 지식 저장고를 만들기 위해 Astro 프레임워크를 선택하고 구현한 과정입니다.

## 주요 기능
- 반응형 헤더 및 레이아웃
- 콘텐츠 컬렉션을 활용한 체계적인 문서 관리
- Neumorphism 디자인 적용
